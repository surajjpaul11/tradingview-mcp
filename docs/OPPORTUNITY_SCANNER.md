# Opportunity research groundwork

The `/opportunities` page scans an editable watchlist of up to 20 stocks. It uses the most recent **completed daily bar** and the same two-year input window as `get_live_signal`. Each stock is fetched once, then the ten strategy runners that expose open positions are checked for a new long entry on that bar. Short signals are not ranked as buys. No orders are placed.

Volume-Confirmed Price Breakout is the tenth runner. Its defaults require a close at least 3% above the preceding close, volume at least twice the preceding 20-bar average, and a close above the preceding 20-bar high. A completed signal enters at the **next bar's open** in backtests, with a two-ATR stop, four-ATR target, and a ten-bar maximum hold. Gaps through a stop/target fill at the actual opening price; ambiguous bars assume the stop first. A signal on the most recent completed bar is marked pending, not filled. This is an initial fixed hypothesis, not a tuned or validated allocation rule. See [the fixed-snapshot check](VOLUME_PRICE_BREAKOUT.md).

The page shows all scanned pairs and highlights current buys. Historical evidence uses only **closed long trades before the signal bar**, with the backtest engine's 0.1% commission and 0.05% slippage on each side. It reports sample size, observed win rate, a Wilson 95% interval, mean net return per trade, and worst trade. Fewer than 20 closed longs are marked as limited history. The `calibrated_gain_probability_pct` field is intentionally `null` for every row: an observed rate, even 9 wins out of 10, is not a 90% chance that today's signal wins.

This is a research surface, not an allocation or recommendation engine. It does not yet condition outcomes on the current volatility/trend regime, test probabilities on untouched dates, estimate portfolio correlation, or model next-eligible fills and gaps consistently. Those are prerequisites for ranking capital allocations. The existing dashboard's imported historical trade database is not used for these estimates; the scanner reruns the strategy code against freshly fetched candles.

Run the dashboard from this worktree with `./start.command` on macOS or `uv run python -m tradingview_mcp.ui.launcher` from a terminal. Open the printed URL and select **Opportunity research**. The JSON endpoint is `/api/opportunities?symbols=GOOGL,AAPL,MELI,SPY,NVDA`.
