Approach 2 — Core + Tactical Overlay (B&H anchor with strategy alpha)

Goal: Force baseline participation so runaway rallies are not missed.

  • Keep a permanent core position (e.g., 40–60% always long).
  • Run curved-channel entries/exits only on remaining tactical sleeve (40–60%).

Why this helps: If ticker goes near-parabolic (SNDK/PLTR-like), core tracks B&H while tactical sleeve can reduce drawdown and add timing alpha.

Approach 3 — Regime-Adaptive Parameter Switching

Goal: Use different behavior in trend vs chop instead of one static rule-set.

  • Define regimes using ADX / slope of SMA200 / volatility expansion.
  • Trend regime: wider stops, fewer exits, pyramid winners, no early mean-revert exits.
  • Chop regime: current tighter exits and quicker profit lock.
  • Persist regime state for minimum bars to avoid flip-flopping.

Validation: Walk-forward test by quarter; compare consistency of delta vs B&H across symbols.
